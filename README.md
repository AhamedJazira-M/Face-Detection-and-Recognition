# Face Recognition (Python + OpenCV)

A simple real-time face recognition project using Haar Cascade for detection and FisherFace Recognizer for recognition.

# Features

Captures and labels face images for multiple users.

Trains a FisherFace model using OpenCV.

Recognizes faces in real-time via webcam.

# Tech Stack

Python, OpenCV, NumPy

# Usage

**Install dependencies:**

`pip install opencv-python opencv-contrib-python numpy`


Edit `person_name` in script and run to collect images.

Repeat for at least two people.

Script then trains and starts real-time recognition.
Press `ESC` to exit.
